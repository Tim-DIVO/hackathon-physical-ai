# hackathon-physical-ai

Physical AI hackathon project.

## Claude Code setup

This repo ships a project-scoped install of [ECC](https://github.com/affaan-m/ECC) (full profile with hooks) under `.claude/`: subagents, skills, slash commands, rules, and the hook runtime. Nothing is installed globally — open the repo in Claude Code and it is picked up automatically. Requires Node.js 18+ for the hooks.
